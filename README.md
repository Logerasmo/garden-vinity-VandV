# Задачи проекта по тонкоплёночным солнечным элементам

Цель — извлечь данные из 90 PDF в `test`, сохранить источник каждого значения и показать результаты и замечания в HTML-интерфейсе. Для разработки используем статьи из `dev` и готовые CSV из `dev_gold`.

## 1. Подготовить статьи

- [ ] Собрать список PDF из `dev` и `test`. Использовать имя файла без `.pdf` как `publication_id`.
- [ ] Извлечь текст, таблицы и подписи к рисункам. Сохранить номера страниц PDF, считая с 1.
- [ ] Записать название, авторов, год и DOI в `publications.csv`.
- [ ] Определить, входит ли статья в область кейса. Для исключённых статей записать `in_scope=false` и причину.

## 2. Извлечь данные из статей

- [ ] Найти состав и класс поглотителя и заполнить `materials.csv`.
- [ ] Найти образцы, присвоить им ID и заполнить `devices.csv`.
- [ ] Определить порядок слоёв от подложки и заполнить `layers.csv`.
- [ ] Найти условия измерений, связать их с образцами и заполнить `measurements.csv`. Прямую и обратную развёртку записывать отдельно.
- [ ] Извлечь `PCE`, `Voc`, `Jsc`, `FF` и остальные показатели из шаблона. Записать каждое значение отдельной строкой в `results.csv` со ссылками на образец и измерение, страницей и местом в статье.
- [ ] Раздельно записать средние и рекордные значения. Пометить цитируемые результаты и связать повторные упоминания через `duplicate_of`. Неуказанные поля оставить пустыми.

## 3. Нормализовать и проверить данные

- [ ] Привести значения к единицам из шаблона, сохранив исходное число и единицу. Например, `343 mV` → `0.343 V`.
- [ ] Проверить КПД по `Voc`, `Jsc`, `FF` и мощности освещения и сравнить `Jsc` по ВАХ и EQE, когда есть необходимые данные.
- [ ] Записать расхождения и противоречия в `issues.csv` с объяснениями, ссылками на результаты и местами в PDF. Сохранить исходные записи.
- [ ] Сверить извлечённые значения, связи и источники с `dev_gold`. Запустить `check_submission.py`.

## 4. Собрать HTML-интерфейс на `dev_gold`

- [ ] Загрузить семь CSV и связать записи по ID статьи, образца и измерения.
- [ ] Показать таблицу результатов с поиском по статьям и фильтрами по материалу, показателю и условиям измерения.
- [ ] Добавить карточку результата с исходным и нормализованным значениями, описанием образца и условиями измерения.
- [ ] Показать страницу, таблицу или цитату, переход к PDF из `dev` и связанные замечания.
- [ ] Проверить интерфейс на образце B4 из `D021.pdf`. В таблице 4 на странице 13 есть средний КПД `2.45%` и рекорд `3.85%`. В тексте и на рисунке 10 указан рекорд `5.25%`. Оба рекорда должны отображаться вместе с замечанием о противоречии.

## 5. Подготовить сдачу

- [ ] Обработать все 90 PDF из `test` и собрать семь CSV по шаблону.
- [ ] Запустить `check_submission.py` на итоговых CSV, исправить ошибки и разобрать предупреждения.
- [ ] Подключить к HTML-интерфейсу итоговые CSV и проверить поиск, фильтры и переходы к источникам.
- [ ] Подготовить паспорт полей и правил, отчёт о проверках и инструкцию по запуску интерфейса.
- [ ] Собрать архив с HTML, JavaScript, итоговыми CSV, паспортом и отчётом. Включить PDF или рабочие ссылки на них.
